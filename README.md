# Wi-Fi Analyzer для Windows

[English guide](README.en.md)

**Региональной блокировки в приложении нет.** Оно не проверяет страну, IP-адрес или регион Windows для доступа к функциям. Доступность каналов и диапазона 6 ГГц зависит от местных требований, Windows, адаптера, драйвера и настроек роутера.

Настольное приложение для Windows 10/11 x64. Использует Windows Native Wi‑Fi API, интерфейс PySide6, графики PyQtGraph и локальную SQLite. Для сканирования нужен включённый Wi‑Fi-адаптер и служба автонастройки WLAN. Можно сканировать через Wi‑Fi, пока интернет идёт через Ethernet. Подключение к точке доступа и monitor mode для сканирования не требуются.

## Запуск

1. На GitHub откройте раздел **Releases** и скачайте `WiFiAnalyzer.exe` из списка **Assets**. Если вы собрали приложение сами, файл находится в `dist/WiFiAnalyzer.exe`.
2. Запустите EXE. Для готовой сборки Python устанавливать не нужно.
3. Выберите Wi‑Fi-адаптер в верхней панели. Первый снимок обычно появляется через несколько секунд. При подключении адаптера после запуска нажмите **Обновить адаптеры**.

Для запуска из исходников распакуйте архив проекта или клонируйте репозиторий. Откройте PowerShell в папке проекта и используйте Python 3.12 x64.

```powershell
py -3.12 -m venv .venv
& .\.venv\Scripts\python.exe -m pip install -r requirements.txt
& .\.venv\Scripts\python.exe main.py
```

Если Windows возвращает «Отказано в доступе», проверьте **Параметры → Конфиденциальность и безопасность → Расположение**. Включите службы геолокации и разрешите доступ классическим приложениям. Список адаптеров можно перечитать кнопкой в верхней панели. [Изменения доступа к Wi‑Fi в Windows](https://learn.microsoft.com/en-us/windows/win32/nativewifi/wi-fi-access-location-changes)

Если адаптер отсутствует в списке, проверьте режим полёта, состояние адаптера и службу **Автонастройка WLAN** (`WlanSvc`). Если у выбранного адаптера нет IPv4-адреса, сканирование по-прежнему доступно. Для диагностики подключите адаптер к Wi‑Fi и повторите запуск ping.

## Работа с приложением

- **Сети.** Выберите адаптер. Таблицу можно сортировать заголовками и фильтровать по диапазону, каналу, RSSI и безопасности. CSV содержит текущий отфильтрованный снимок.
- **График каналов.** Выберите диапазон, масштабируйте колёсиком и выделяйте точку через список, график или таблицу. Круг показывает RSSI на частоте приёма при неизвестной ширине. Заливка обозначает геометрическое перекрытие объявленных полос, включая номинальную полосу при EHT puncturing.
- **Монитор RSSI.** Двойной щелчок по сети открывает её историю. График и статистика показывают последние 720 записей. CSV выгружает всю историю выбранной точки на данном адаптере. Если успешный скан пропустил выбранную точку, в истории появляется пустой RSSI. Ошибка сканирования показывает устаревший снимок.
- **Диагностика.** Для проверки подключите выбранный адаптер к Wi‑Fi. Запустите ping до его IPv4-шлюза. Для внешней проверки укажите доступный вам IPv4-адрес. Приложение показывает RTT, долю проб без ответа, восстановление после пропуска и ближайшее по времени измерение RSSI подключённой точки. Блокировка ICMP может выглядеть как потеря. Пауза сканирования полезна, если нужно проверить задержку без дополнительной нагрузки от активных сканов. При смене сетевых настроек перезапустите диагностику для обновления IP и шлюза.
- **Channel Advisor.** Введите каналы, которые роутер разрешает использовать в выбранном диапазоне. Рекомендации строятся по свежему снимку и сортируются внутри каждой ширины 20, 40 или 80 МГц. В 2,4 ГГц варианты 80 МГц отсутствуют. Приложение не меняет настройки роутера.

Настройки, история и журналы лежат в `%LOCALAPPDATA%\WiFiAnalyzer`. Для производителя можно положить туда локальный CSV IEEE MA-L под именем `oui.csv`, с колонками `Assignment` и `Organization Name`, и перезапустить приложение. При локально назначенном BSSID производитель остаётся неизвестным. Для работы не нужен интернет. Телеметрии нет. Сетевые запросы вне локальной сети возникают при запуске диагностики с указанным внешним адресом.

## Возможности Native Wi-Fi API

- `WlanEnumInterfaces` перечисляет адаптеры отдельно от Ethernet. `WlanScan` асинхронный. Приложение ждёт ACM-уведомление до четырёх секунд, затем запрашивает BSS. Попытки идут примерно раз в пять секунд, по одной на выбранный адаптер. Драйвер и Windows могут ограничивать сканирование. [Microsoft WlanScan](https://learn.microsoft.com/en-us/windows/win32/api/wlanapi/nf-wlanapi-wlanscan)
- `WlanGetNetworkBssList` возвращает RSSI, качество в процентах, частоту приёма Beacon/Probe Response и предоставленные драйвером Information Elements. Частота приёма и центр всей рабочей полосы показаны раздельно. Канал вычисляется из частоты приёма, а при разборе полосы проверяется согласованность с Operation IE. [Microsoft WLAN_BSS_ENTRY](https://learn.microsoft.com/en-us/windows/win32/api/wlanapi/ns-wlanapi-wlan_bss_entry)
- Для ширины разбираются HT Operation, VHT Operation, HE Operation (VHT-поля и параметры 6 ГГц) и EHT Operation. Поддерживаются 20/40/80/160 МГц, раздельные сегменты 80+80 и объявленная номинальная полоса 320 МГц. При неполных, несовместимых или отсутствующих полях используется «Не определено». Видимость сетей 6 ГГц зависит от Windows, драйвера, региона и адаптера. [Реализация Linux mac80211](https://github.com/torvalds/linux/blob/master/net/mac80211/mlme.c), [поля EHT Operation](https://github.com/torvalds/linux/blob/master/include/linux/ieee80211-eht.h)
- Защита определяется по WPA/RSN AKM и флагу Privacy. Один Privacy не позволяет уверенно определить протокол. Текущий BSSID запрашивается через `WlanQueryInterface`. Диагностика использует исходный IPv4-адрес выбранного адаптера через `IcmpSendEcho2Ex`. [Microsoft IcmpSendEcho2Ex](https://learn.microsoft.com/en-us/windows/win32/api/icmpapi/nf-icmpapi-icmpsendecho2ex)

### Методика Channel Advisor

Для каждого блока из разрешённых 20‑МГц каналов суммируются вклады соседних BSS. Вклад равен относительной мощности по RSSI, умноженной на долю полосы кандидата, которая пересекается с полосой BSS. При неизвестной ширине частота внутри блока добавляет полный вклад, а уверенность понижается. Подключённый BSSID исключается. При отсутствии наблюдаемых соседей уверенность тоже низкая. Оценка служит для сравнения кандидатов одной ширины. Сканирование не измеряет занятость эфира, активность клиентов или не-Wi‑Fi-помехи. Регуляторные требования и DFS зависят от роутера и региона.

## Тесты и сборка

```powershell
& .\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\build.ps1 -Python .\.venv\Scripts\python.exe
```

Для проверки на реальном оборудовании откройте приложение при активном Ethernet и включённом Wi-Fi, выберите адаптер и дождитесь снимка. Проверьте кривые и маркеры неизвестной ширины. Затем подключите Wi‑Fi к точке и проверьте подсветку BSSID и ping до её IPv4-шлюза. Для проверки потерь и восстановления временно прервите Wi-Fi-подключение, затем восстановите его.

Сборка проверена на Windows 11 x64 с Intel Wi‑Fi 6 AX201 и активным Ethernet. EXE записал 21 реальное измерение в SQLite при Wi‑Fi-адаптере, не подключённом к точке доступа. На этом стенде также проверены пять вкладок на реальном снимке и локальный вызов ICMP через loopback. Ping через подключённую точку, диапазон 6 ГГц и запуск на Windows 10 требуют отдельной проверки на подходящем оборудовании.
